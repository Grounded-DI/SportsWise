## Structural finding: qualification versus resource state

In the report's qualification scenario, Philadelphia could advance by winning its own game or by losing while Arizona also lost. Qualification therefore has an external escape path.

Using Wheeler can improve immediate qualification probability while consuming pitching availability for the next elimination series. **“IN with Wheeler preserved” and “IN with Wheeler consumed” pass the same qualification gate but carry different downstream resources.** Maximizing qualification, qualifying with a stronger rotation, and maximizing championship probability can therefore require different objective functions.

The record establishes the structural tradeoff. It does not establish which strategy was optimal.
